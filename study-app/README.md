# 問題集管理

スマートフォン向けの復習管理アプリです。依存パッケージのインストールは不要です。

## 起動・検証

このフォルダーで `node server.mjs` を実行し、表示される `http://localhost:4173` を開きます。同じWi-Fiのスマートフォンでも使う場合は `node server.mjs --lan` で起動し、PCのLANアドレスとポート4173を指定します（PC側のファイアウォール設定が必要な場合があります）。HTMLを直接ダブルクリックするのではなく、このHTTPサーバー経由で開いてください。

## GitHub Pagesで使う

Sitesや外部の実行基盤への依存はありません。`dist/` はそのまま静的配信できます。

1. **この `study-app` フォルダーの中身だけ**をGitHubリポジトリのルートに置き、`main` ブランチへpushします。上位フォルダーの問題・回答・PDFなどは含めません。
2. GitHubリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。
3. **Actions → Test and deploy GitHub Pages → Run workflow** を実行します。その後の `main` へのpushでは、テスト成功後に自動配信します。
4. 配信完了後に表示されるPagesのURLをスマートフォンで開きます。

`.github/workflows/pages.yml` が構文チェック・テスト・`dist/` の配信を担当します。アセットは相対パスなので `https://ユーザー名.github.io/リポジトリ名/` でも動作します。リポジトリを作成・pushする操作はまだ行っていません。

ローカル版からGitHub Pages版へ移行する際は、ローカル版でバックアップを書き出し、Pages版で読み込んでください。保存領域は配信元ごとに異なります。

`node --test tests/core.test.mjs tests/app.test.mjs` で日付・復習ルール・データ検証とアプリの保存操作を確認します。`node --check dist/app.js` と `node --check dist/core.js` で構文を検証します。npmがある環境では `npm start`・`npm test`・`npm run check` も使えます。

## 画面と保存

- ホーム：教材ごとの今日の復習。未実施の問題は自動で翌日に繰り越します。
- 入力：今日の復習、または開始問題番号からの新しいサイクル。結果は1問ごとに保存し、途中終了・直前の取り消しができます。
- カレンダー：7日間、日別詳細、教材別・問題別の直近／次の予定。
- 入力左上の編集：教材追加・概要編集・過去の正誤の一括修正。修正前に次回予定を確認します。
- バックアップ：JSONを書き出し・復元。復元は置き換えで、現在のデータを事前に書き出します。

保存先はブラウザーのlocalStorageです。同じ端末・同じブラウザー・同じ配信URLで継続利用します。端末間の自動同期はありません。プライベートブラウジングやブラウザーデータの削除で消える可能性があるため、定期的にバックアップしてください。画面に学習データを埋め込んで配信することはありません。

## 復習ルール

- 〇：入力日から30日後。
- △：入力日から7日後と30日後。30日後は独立した予定として保持し、7日後の復習結果に依存しません。
- ×：最初の×の日から1・3・7・14・30日後。未実施で繰り越した場合は基準日も同じ日数ずらし、復習間隔を保ちます。30日段階でも×なら入力日から30日後を繰り返します。
- ×のあと〇・△なら、それぞれのルールに切り替えます。
- 各問題の表示対象は未実施の予定の直近1件だけ。同日の複数予定はまとめます。
- 復習で入力すると、その日までの予定を消化し、通常の次回予定を更新します。△が作った未来の30日予定は保持します。
- 新しいサイクルはその問題の×の連続回数をリセットします。△の独立した未来の30日予定は保持します。
- 履歴から予定を計算するため、過去の正誤を訂正すると後続の予定も再計算されます。

## 予定日に実施できなかった場合

未実施の問題について、直近の予定を翌日へ移し、その問題の後続の予定もすべて1日後ろへずらします。他の問題や教材の予定は変更しません。複数日未実施の場合は、経過した日数分まとめてずらします。

例：△で11/9と12/2に予定があり、11/9に未実施なら、11/10と12/3へ移動します。11/10に〇を入力しても、ずらした12/3の予定は残り、入力日から30日後の12/10も設定します。

履歴と現在の日付から予定を計算するため、アプリを閉じていても次に開いたときに繰越が反映されます。再読み込みで二重にずれることはありません。画面を開いたままの日付変更も30秒以内、または画面へ戻ったタイミングで反映します。実際に学習した日付は書き換えません。

日付は利用端末のローカル日付に従います。通知・リマインダープッシュは今回の対象に含めていません。
